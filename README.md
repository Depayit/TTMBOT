# TTMBOT

TTMBOT v2.0 — Desktop Automation Console for Windows.

## Overview

TTMBOT is a desktop ticket automation console for Windows featuring ticketing automation, AI vision recovery, browser management, live control, multi-worker processes, and commercial management.

## Project Structure

- `dist/` — Production landing page source
  - `dist/index.html` — Landing page UI
  - `dist/assets/` — Stylesheets, icons, and media assets
